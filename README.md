# feliz_dia_ma.exe

Un recorrido jugable para mamá: una terminal que se escribe sola, un bug que se arregla con `Infinity`, un chat con la IA, componentes que se renderizan, un camino de fotos y una carta al final.

## Cómo abrirlo

Es HTML, CSS y JavaScript sin dependencias. Hay que servirlo desde un servidor local (por ejemplo):

```bash
python -m http.server 5173
```

y abrir `http://localhost:5173`.

## Archivos

- `index.html`: estructura de la página
- `styles.css`: estilos y animaciones
- `app.js`: pantallas, textos y lógica del recorrido
- `fotos/`: fotos optimizadas para web
